Netflix AI Dashboard



Project Overview



This project is an interactive Netflix AI Dashboard built using Streamlit, Pandas, and Plotly.



Features



\- Dataset Overview

\- Data Cleaning

\- KPI Metrics

\- Interactive Filters

\- Pie Chart

\- Line Chart

\- Bar Chart

\- Histogram

\- Scatter Plot



Technologies Used



\- Python

\- Pandas

\- Streamlit

\- Plotly



Dataset



Netflix Titles Dataset



How to Run



1\. Install required libraries:



pip install streamlit pandas plotly



2\. Run the application:



streamlit run app.py
